## What is this

This repository is a public timestamped record of the MEDIOEVO ecosystem — a 25-year project by L.R. González that spans:

- A 35-book sci-fi saga (~3,000,000 words), started in 2001 at age 14
- **Observacionismo** — an epistemic framework developed independently before AI work
- **OSIT** — a proposed cognitive firmware architecture for AI systems
- **TUIP-Σ** — a unified information-perception physical framework
- **DUAT Agent City** — a multi-agent city simulator with Observer Collapse mechanics
- **Claudio** — a sovereign local AI agent (Python/Flask/Ollama)
- **Wabi-Sabi** — a local LLM codegen system with gated autonomy
- **Curador SETO** — a knowledge curation architecture (337 sources processed)
- **FCU v2.0** — a continuity framework for multi-session AI work
